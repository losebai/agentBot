# AgentBot 0.6.0 升级说明

适用起点：已正常完成数据库升级的下载站 0.5.11 部署。
本版与已发布 0.5.11 的 MySQL、SQLite 完整初始化及增量 SQL 一致，
不新增表、字段、索引或约束，无需新的迁移 SQL。
启动仍按既有清单核验数据库；已完成增量不重复执行，仅推进程序版本记录至 0.6.0。

## 升级顺序与数据影响

1. 停止旧实例，备份 `.env`、业务数据库、独立队列库及媒体目录。
   SQLite 备份应包含 WAL 中的数据并保持一致。
2. 安装 0.6.0，保留已有配置、密钥、数据库、素材和表情包原件，再手动启动后端。
   不重新初始化已有数据库，不批量执行历史 SQL。
3. 本版改进表情包实际图片格式识别与静态预览处理，保留原件动画；
   核对图库上传、识图、语境检索和发送功能，识图继续使用独立配置的模型。
4. 工作流缺少必需原图时提供明确提示，不虚构图片输入；核对原图来源和工作流选择。
   本版还改进回复与媒体发送处理，保留现有 Agent、人格、工具授权和插件启用选择。

新库继续使用 `agent_bot_init.sql` 或 `agent_bot_init.sqlite.sql`，
独立队列使用 `agent_bot_queue_init.sqlite.sql`。
发布包包含两种业务数据库的完整初始化、既有适用增量及升级说明。
更早部署先核对 [0.5.11 升级说明](UPGRADE-0.5.11.md) 和原版本所需历史迁移；
自动升级仅执行明确登记且适用的步骤，详见 [自动升级说明](UPGRADE-AUTOMATIC.md)。

回退前停止程序并核对数据库版本兼容性；完整回退使用升级前同一时刻的一致备份。
