# B 站插件数据库升级

适用起点：agent_bot 0.5.7 的完整结构，或已经完成此前适用迁移的既有数据库。

新数据库执行当前对应后端的 `agent_bot_init.sql` 或 `agent_bot_init.sqlite.sql`，已经包含 B 站表，不需要再执行增量。

既有数据库按以下顺序操作：

1. 备份所选数据库，保留现有启动配置与密钥。
2. 启动程序会按[自动升级清单](UPGRADE-AUTOMATIC.md)执行对应后端的 B站增量；也可提前运行 `agent-bot database upgrade`。
3. 在插件管理启用“B站”，保存后手动重启后端，再扫码登录。

增量只新增 `agent_bot_bilibili_account`、`agent_bot_bilibili_operation`，不重建、删除或修改已有业务表。普通启动在读取配置前完成版本核对及所需增量，未启用 B站也会维护统一业务结构。初始化与增量使用相同字段和约束。

账号 Cookie 保存在当前选择的数据库中，不进入 `.env`、页面配置和工具结果。数据库备份按已有凭据保护要求保存。清除本地登录不会清除操作记录，也不等于其他设备退出。

操作表主键对单请求相同参数的投稿、回复去重。`pending` 表示进行中或结果未知；异常中断后不能自动重试。请先在 B 站核对是否已投稿或发送评论，再按需发起新请求，不要把所有 pending 批量改为成功或删除。

回退时停用 B 站插件并重启；保留新增表即可，不需要删除账号或历史数据。发布包显式包含本说明、两份增量和两份完整初始化脚本。
