# AgentBot 0.5.11 升级说明

适用起点：已正常完成此前升级的下载站 0.5.10 部署。
相较已发布的 0.5.10，本版包含 Agent 独立人格字段和表情包图库增量。
清单中 `agent-personality-v1`、`stickers-v1` 的既有目标版本保持 0.5.10，
升级完成后的程序版本登记为 0.5.11；已完成流水不重复执行。

## 升级顺序与数据影响

1. 停止旧实例，备份 `.env`、业务数据库、独立队列库及媒体目录。
   SQLite 备份应包含 WAL 中的数据并保持一致。
2. 安装 0.5.11，保留已有配置、密钥和数据库，再手动启动后端。
   启动读取配置前按明确清单自动升级；也可停服后先运行 `agent-bot database upgrade`。
3. 既有历史增量完成后，先执行对应后端的 `agent-personality.sql` /
   `agent-personality.sqlite.sql`，新增 `agent_bot_agent.personality_prompt`。
   旧 Agent 人格初始化为空，角色设定、模型、工具权限和关联原样保留。
   SQLite 使用非空文本及空字符串默认值；MySQL 先新增可空列、回填该列再收紧非空，
   不设置文本默认值。中断重入由升级器核验列状态，不能盲目重复执行 ADD COLUMN。
4. 再执行 `stickers-init.sql` / `stickers-init.sqlite.sql`，仅新增
   `agent_bot_sticker` 表及索引、约束，不改写已有业务数据，不自动启用插件。
   独立 SQLite 队列不执行这些业务库增量。不要重跑完整初始化或批量执行历史 SQL。
5. Agent 管理改为内联编辑并增加独立人格；核对原角色、模型及工具授权。
   按需在插件管理启用表情包插件并重启，配置识图模型及图库；图片原件不随发布包分发。
6. 本机 `ls`、`bash` 工具需为 Agent 显式授权，不自动扩大已有权限。
   管理端可调用，QQ 仅真实机器人主人可调用；命令使用后端系统账户权限，
   Windows 实际使用 PowerShell。启用前核对后端账户和工具授权。
7. 核对机器人连接、人格设置、表情包图库及原有工作流。
   SQLite 失败整体回滚；MySQL DDL 可能保留已完成步骤，失败停止启动并保留流水。

新库只执行对应后端的 `agent_bot_init.sql` 或 `agent_bot_init.sqlite.sql`，
其中包含当前完整结构；独立队列使用 `agent_bot_queue_init.sqlite.sql`。
发布包同时提供两种业务库的完整初始化、适用增量、升级说明及历史工具。
更早部署先核对原版本历史迁移；自动升级只执行明确登记且适用的步骤。
重入、锁与失败处理详见 [自动升级说明](UPGRADE-AUTOMATIC.md)。

回退前停止程序并核对数据库版本兼容性；完整回退使用升级前同一时刻的一致备份。
