# AgentBot 0.5.6 升级说明

适用起点：已完成 [0.5.5 数据库升级](UPGRADE-0.5.5.md) 的 MySQL 或 SQLite 部署。
本结论基于当前源码与已发布、SHA256 校验通过的 0.5.5 wheel 对比；
如果后续继续修改数据库结构，发布前须重新核对并补充适用增量。

## 数据库影响

从上述起点升级到当前 0.5.6 源码，**无需新增数据库迁移 SQL，也无需运行数据迁移工具**。

- `agent_bot_init.sql` 与 `agent_bot_init.sqlite.sql` 与已发布 0.5.5 一致。
- 独立队列的 `agent_bot_queue_init.sqlite.sql` 与已发布 0.5.5 一致。
- 原有已打包迁移 SQL 未发生变化，本次无需重跑 0.5.5 或更早的迁移。
- 新增自动发言配置使用现有运行配置表；图生视频复用现有工作流、媒体及队列结构。
  不需要手工插入配置行或重新初始化数据库。

新安装继续使用对应后端的完整初始化 SQL。发布包仍交付完整 SQL 和历史适用增量，
但不能把包内全部历史脚本批量执行到已有库，更不能重复执行退役旧表脚本。

## 升级顺序与行为核对

1. 停止旧实例，备份启动文件、业务数据库、独立队列库和媒体目录。
   SQLite 备份须保存含 WAL 数据的一致快照。
2. 安装新程序，保留已有 `.env`、数据库、密钥和媒体目录，不重新初始化已有库。
3. 启动后检查机器人配置、模型绑定、工作流、媒体和记忆。
4. 核对“机器人配置 → LLM设置”的 `chat_agent_max_steps`：
   本版统一按工具调用次数计数，默认 5 次，已保存的 null 表示不限次数。
   旧 Agent 预设 `max_steps` 和 `chat_web_search_max_steps` 不再决定执行预算。
5. 自动发言新增独立 LLM 决策选项；原 Laya 方式保持默认。
   需要使用 LLM 时在管理页面显式选择决策方式、独立模型与提示词。
6. 图生视频属于可选功能，启用前按 H3 部署说明安装配套 ComfyUI 节点和模型，
   导入并启用工作流，再向目标 Agent 授权视频工具；程序升级不自动启用这些权限。

版本更新不会自动修改启动配置或切换数据库后端。普通启动不执行历史数据库升级。
回退前先停服并核对升级后新增数据与旧程序的兼容性；需要完整回退时，
恢复升级前程序、配置和同一时刻的数据库及媒体备份。
