# AgentBot 0.5.9 升级说明

适用起点：已正常完成数据库升级的 0.5.8 部署。
本版与已发布 0.5.8 的 MySQL、SQLite 完整初始化及增量 SQL 一致，
不新增表、字段、索引或约束，无需执行新的迁移 SQL。
启动仍按既有清单核验数据库；已完成的迁移不重复执行，仅推进程序版本记录。

## 升级顺序与数据影响

1. 停止旧实例，备份 `.env`、业务数据库、独立队列库及媒体目录。
   SQLite 备份应包含 WAL 中的数据并保持一致。
2. 安装 0.5.9，保留已有配置、密钥和数据库，再手动启动后端。
   不重新初始化已有数据库，不批量执行历史 SQL。
3. 本版增加 MCP 连接阶段和 HTTP 状态诊断，日志不记录令牌或响应正文；
   管理页面的校验错误提供字段定位及中文规则提示，不回显输入值和原始异常。
4. 工具参数 schema 保留合法的 `format` 注解，不额外执行格式检查；
   类型、字段约束及业务模型校验继续生效。核对 MCP 工具发现、调用及配置保存。

新库继续使用 `agent_bot_init.sql` 或 `agent_bot_init.sqlite.sql`，
独立队列使用 `agent_bot_queue_init.sqlite.sql`。
发布包包含两种业务数据库的完整初始化、既有适用增量和升级说明。
更早部署先核对 [0.5.8 升级说明](UPGRADE-0.5.8.md) 及原版本所需历史迁移；
自动升级只执行明确登记的适用增量，详见 [自动升级说明](UPGRADE-AUTOMATIC.md)。

回退前停止程序并核对旧程序与数据库版本兼容性；完整回退使用升级前一致备份。
