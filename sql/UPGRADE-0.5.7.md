# AgentBot 0.5.7 升级说明

适用起点：已完成历史数据库迁移的 0.5.6 部署。
本版同步提供 MySQL、SQLite 的完整初始化 SQL、B站与启动版本管理增量；独立 SQLite 队列不执行这些业务库增量。
**当前源码新增 B站及启动版本管理表，启动时会按[自动升级清单](UPGRADE-AUTOMATIC.md)执行对应后端增量；不重跑历史迁移，不重新初始化已有数据库。**
更早部署仍须按 [0.5.5](UPGRADE-0.5.5.md) 和 [0.5.6](UPGRADE-0.5.6.md) 说明处理适用升级。

## 升级顺序与影响

1. 停止旧实例，备份启动文件、业务数据库、独立队列库和媒体目录。
   SQLite 备份须包含 WAL 中的数据，保留一致快照。
2. 安装 0.5.7，保留已有 `.env`、数据库、密钥和媒体目录，再手动启动。
3. 本版新增自动多条回复配置，默认关闭，配置复用现有运行配置表。
   启用前在机器人配置中核对消息数量、发送间隔及提示词。
4. LLM 自动发言决策现使用当前消息与近期群聊快照作为本次输入；
   输入和输出保存在系统调用归档，不进入聊天历史。升级后核对独立决策模型及提示词。
5. 启动前会核对数据库版本，自动执行已登记且适用的增量；失败停止启动，不自动降级。
6. 在插件管理启用 B站后重启，再扫码登录；为 Agent 按需授权投稿、评论读取、回复和登录检测工具。核对机器人连接、配置、会话、工作流与媒体功能。

新安装继续使用对应后端的 `agent_bot_init.sql` 或 `agent_bot_init.sqlite.sql`，
队列使用独立的 `agent_bot_queue_init.sqlite.sql`。
发布包保留完整 SQL 和历史适用增量，但不得批量执行全部历史脚本。

本版还更新了发布脚本与资源打包；项目版本可通过 `-Version` 定向同步，
Git 忽略的内置资源显式保留在源码包中，支持从源码包重建 wheel。
回退须先停服并核对新版本数据与旧程序的兼容性；完整回退使用升级前同一时刻的备份。
