# AgentBot 0.5.8 升级说明

适用起点：已完成此前模型身份、会话及记忆迁移的 0.5.7 部署。
相较下载站已发布的 0.5.7，本版新增 B站插件及启动数据库自动升级；需要数据库增量。
更早版本先核对各自升级说明，自动升级不会补做未登记的历史数据转换。

## 升级顺序与数据影响

1. 停止旧实例，备份 `.env`、业务数据库、独立队列库和媒体目录。
   SQLite 应保存含 WAL 数据的一致备份；停止共享同一数据库的旧程序。
2. 安装 0.5.8，保留已有配置、密钥和数据，再手动启动后端。
3. 首次启动在读取配置及监听网络前核对业务库结构，先补齐对应后端的
   `startup-versioning.sql` / `startup-versioning.sqlite.sql`，再按登记清单执行
   `bilibili-init.sql` / `bilibili-init.sqlite.sql`，最后登记程序版本 0.5.8。
   已有迁移 ID `bilibili-v1` 的目标版本保持 0.5.7，不修改已应用流水。
   也可停服后先运行 `agent-bot database upgrade`，不要重复初始化或批量执行历史 SQL。
4. 增量只新增版本记录、迁移流水、B站账号及操作记录四张表，不删除已有业务数据。
   未启用 B站也会维护统一结构；独立 SQLite 队列不执行这些业务库增量。
   SQLite 失败整体回滚；MySQL DDL 可能保留已完成步骤，失败停止启动并保留错误状态。
5. 在“插件管理”按需启用 B站，保存并重启后端后扫码登录；在 Agent 中按需授权
   登录检测、评论读取、评论回复和视频投稿工具。真实登录及投稿需使用自己的账号验收。
6. 本版移除内置搜索工具，外部搜索统一通过 MCP 配置；升级后核对 Agent 工具授权。
   核对机器人连接、会话、媒体和工作流。运行配置与密钥不由安装器覆盖。

新库只执行对应后端的 `agent_bot_init.sql` 或 `agent_bot_init.sqlite.sql`，
其中已包含全部表；独立队列使用 `agent_bot_queue_init.sqlite.sql`。
SQL 下载包同时提供完整初始化、适用增量、历史脚本和升级工具，不能批量运行归档脚本。
自动升级的锁、校验和及失败处理见 [自动升级说明](UPGRADE-AUTOMATIC.md)，
B站数据与权限说明见 [B站升级说明](UPGRADE-BILIBILI.md)。

新程序会拒绝访问更高版本的数据库。回退前停止程序，核对旧版兼容性；
完整回退应恢复升级前同一时刻的程序、配置和数据库备份。
