# AgentBot 0.6.2 升级说明

适用起点：已正常完成数据库升级的下载站 0.6.1 部署。
本版与已发布 0.6.1 的 MySQL、SQLite 完整初始化及增量 SQL 一致，
不新增表、字段、索引或约束，无需新的迁移 SQL。
启动继续核验数据库，已完成增量不重复执行，仅推进程序版本记录至 0.6.2。

## 升级顺序与数据影响

1. 停止旧实例，备份 `.env`、业务数据库、独立队列库、媒体目录及 `data/napcat/`。
   SQLite 备份应包含 WAL 中的数据并保持一致。
2. 安装 0.6.2，保留已有配置、密钥、数据库及登录资料，再手动启动桌面程序。
   不重新初始化数据库，不批量执行历史 SQL。
3. 桌面 NapCat 改为独立 Node 运行方式，安装包携带经过摘要校验的固定运行资源，
   无需用户另装 Node，不定位、注入或修改系统 QQ，不接管其他 QQ 或 NapCat。
   新载荷使用 `runtime/napcat-node/`；保留旧 `runtime/napcat/` 不影响升级。
4. 在“插件管理 → QQ 配置”启动所属 NapCat，并在页面扫描二维码。
   首次成功登录默认记住账号，后续启动尝试使用已保存凭据快速登录；
   已有自动登录账号不覆盖，不保存 QQ 密码。快速登录失败时按页面提示扫码。
   核对 OneBot 连接及所属账号，普通命令行服务仍使用外部接入方式。

新库继续使用 `agent_bot_init.sql` 或 `agent_bot_init.sqlite.sql`，
独立队列使用 `agent_bot_queue_init.sqlite.sql`。
发布包包含两种业务库的完整初始化、既有适用增量和升级说明。
更早部署先核对 [0.6.1 升级说明](UPGRADE-0.6.1.md) 及原版本所需历史迁移；
自动升级仅执行明确登记的适用步骤，详见 [自动升级说明](UPGRADE-AUTOMATIC.md)。

回退前停止程序并核对数据库版本及运行资源兼容性；完整回退使用升级前一致备份。
